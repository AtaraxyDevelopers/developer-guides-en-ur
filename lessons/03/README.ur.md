# 03. اندراج کی جانچ میں پروگرام کو محفوظ رکھیں

[English](README.en.md) · [کوڈ](example.mjs)

<div dir="rtl" lang="ur">

## آپ کیا سیکھیں گے

کسی فیلڈ کو پڑھنے سے پہلے جانچیں کہ اندراج واقعی ایک آبجیکٹ ہے۔ واضح پیغام واپس دیں تاکہ صارف غلطی درست کر سکے۔ قسم کی جانچ اور کاروباری شرط الگ رکھیں۔ ہر درخواست میں درست آبجیکٹ آنے کا مفروضہ نہ بنائیں۔

## خود آزمائیں

null، ایک فہرست، اور ایسا آبجیکٹ دیں جس میں نام عدد ہو۔ پروگرام بند نہیں ہونا چاہیے۔

example.mjs میں فنکشن پڑھیں، ایک تبدیلی کریں، پھر سبق اور ٹیسٹ دوبارہ چلائیں۔ ٹیسٹ کے نتیجے کی وجہ بھی سمجھیں۔

</div>

ریپوزٹری کے بنیادی فولڈر سے یہ کمانڈ چلائیں:
