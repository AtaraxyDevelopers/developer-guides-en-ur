# 08. خفیہ معلومات کو آؤٹ پٹ سے دور رکھیں

[English](README.en.md) · [کوڈ](example.mjs)

<div dir="rtl" lang="ur">

## آپ کیا سیکھیں گے

ترتیبات کو واضح ماحولیاتی آبجیکٹ سے پڑھیں۔ مطلوبہ ٹوکن کی موجودگی جانچیں، مگر تشخیصی جواب میں صرف یہ بتائیں کہ وہ مقرر ہے یا نہیں۔ مسئلہ تلاش کرتے وقت اصل ٹوکن کبھی پرنٹ نہ کریں۔

## خود آزمائیں

خالی ٹوکن دیں تو خطا آنی چاہیے۔ یہ بھی جانچیں کہ خلاصے میں اصل ٹوکن شامل نہیں ہوتا۔

example.mjs میں فنکشن پڑھیں، ایک تبدیلی کریں، پھر سبق اور ٹیسٹ دوبارہ چلائیں۔ ٹیسٹ کے نتیجے کی وجہ بھی سمجھیں۔

</div>
