# 09. UTC تاریخ کی حد سمجھیں

[English](README.en.md) · [کوڈ](example.mjs)

<div dir="rtl" lang="ur">

## آپ کیا سیکھیں گے

ایک لمحہ اور کیلنڈر کی تاریخ الگ تصورات ہیں۔ ٹائم زون کے فرق والا وقت UTC میں پچھلے دن کا ہو سکتا ہے۔ UTC تاریخ لینے سے پہلے وقت تبدیل کریں اور غلط وقت پر واضح خطا دیں۔

## خود آزمائیں

UTC+05:00 کی آدھی رات کا UTC کی آدھی رات سے موازنہ کریں۔ صرف تاریخ والے سالگرہ کے اندراج پر یہ تبدیلی استعمال نہ کریں۔

example.mjs میں فنکشن پڑھیں، ایک تبدیلی کریں، پھر سبق اور ٹیسٹ دوبارہ چلائیں۔ ٹیسٹ کے نتیجے کی وجہ بھی سمجھیں۔

</div>

ریپوزٹری کے بنیادی فولڈر سے یہ کمانڈ چلائیں:

```sh
npm run lesson -- 09
```

متوقع نتیجہ:

```json
{
  "utcDay": "2025-12-31"
}
```

اس سبق میں سیکنڈ اور واضح ٹائم زون والا ISO وقت استعمال کریں۔ اعشاری حصے میں ایک سے تین ہندسے ہو سکتے ہیں۔ گھنٹے صفر سے 23 تک ہوں۔ ناممکن تاریخیں اور لیپ سیکنڈ قبول نہیں کیے جاتے۔ UTC میں تبدیلی سے پہلے کیلنڈر کی تاریخ الگ جانچی جاتی ہے۔
