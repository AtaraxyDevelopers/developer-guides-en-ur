# 05. JSON فائل لکھیں اور پڑھیں

[English](README.en.md) · [کوڈ](example.mjs)

<div dir="rtl" lang="ur">

## آپ کیا سیکھیں گے

ڈیٹا کو UTF-8 JSON میں لکھیں، پھر فائل پڑھ کر اسے دوبارہ آبجیکٹ میں تبدیل کریں۔ ایک الگ عارضی فولڈر استعمال کریں اور finally میں صفائی کریں، تاکہ خطا آنے پر بھی فائلیں باقی نہ رہیں۔ یہ مشق ہے، مکمل ڈیٹابیس نہیں۔

## خود آزمائیں

اردو میں ایک فیلڈ شامل کریں اور دوبارہ پڑھ کر اس کا موازنہ کریں۔ جانچیں کہ خطا آنے پر بھی عارضی فولڈر حذف ہو جاتا ہے۔

example.mjs میں فنکشن پڑھیں، ایک تبدیلی کریں، پھر سبق اور ٹیسٹ دوبارہ چلائیں۔ ٹیسٹ کے نتیجے کی وجہ بھی سمجھیں۔

</div>

ریپوزٹری کے بنیادی فولڈر سے یہ کمانڈ چلائیں:

```sh
npm run lesson -- 05
```

متوقع نتیجہ:

```json
{
  "message": "السلام علیکم",
  "synthetic": true
}
```
