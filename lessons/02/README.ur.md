# 02. متن کی یکساں صورت اور نقل کی پہچان

[English](README.en.md) · [کوڈ](example.mjs)

<div dir="rtl" lang="ur">

## آپ کیا سیکھیں گے

ایک جیسا دکھائی دینے والا متن یونیکوڈ میں مختلف صورتوں میں لکھا جا سکتا ہے۔ موازنہ کرنے سے پہلے NFC استعمال کریں اور ابتدا و انتہا کی خالی جگہ ہٹائیں۔ پہلی قدر محفوظ رکھیں۔ یہ مثال ناموں کی ثقافتی درستی کا فیصلہ نہیں کرتی۔

## خود آزمائیں

ایک حرف کو مرکب اور غیر مرکب دونوں صورتوں میں شامل کریں۔ نتیجے میں صرف ایک قدر رہنی چاہیے۔

example.mjs میں فنکشن پڑھیں، ایک تبدیلی کریں، پھر سبق اور ٹیسٹ دوبارہ چلائیں۔ ٹیسٹ کے نتیجے کی وجہ بھی سمجھیں۔
