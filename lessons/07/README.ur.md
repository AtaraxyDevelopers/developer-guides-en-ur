## آپ کیا سیکھیں گے

ٹیسٹ بتاتا ہے کہ کال کرنے والے کو کون سا نتیجہ ملنا چاہیے۔ پہلے عام مثال جانچیں، پھر خالی فہرست اور غلط اندراج شامل کریں۔ Node میں جانچ کے لیے assertion لائبریری اور ٹیسٹ رنر موجود ہیں، اس لیے اضافی پیکیج ضروری نہیں۔

## خود آزمائیں

npm test چلائیں۔ جمع کرنے کا طریقہ بدل کر ناکام ٹیسٹ دیکھیں، پھر درست کوڈ واپس رکھیں۔

example.mjs میں فنکشن پڑھیں، ایک تبدیلی کریں، پھر سبق اور ٹیسٹ دوبارہ چلائیں۔ ٹیسٹ کے نتیجے کی وجہ بھی سمجھیں۔
